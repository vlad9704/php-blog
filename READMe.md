# PHP Blog

Тестовый проект блога на PHP без фреймворков.

## Стек

- PHP 8.3
- MySQL 8.4
- Smarty 5
- SCSS
- Docker Compose

## Возможности

- Главная страница с непустыми категориями и тремя последними статьями каждой категории.
- Страница категории с сортировкой по дате публикации или просмотрам.
- Пагинация по 5 статей.
- Страница статьи со счётчиком просмотров.
- До трёх похожих статей с общими категориями.
- Привязка статьи к нескольким категориям.
- Сидинг тестовых данных.
- Адаптивное оформление.

## Запуск

Нужны Git и Docker с поддержкой Docker Compose.
В Windows необходимо запустить Docker Desktop.

Из корня проекта выполните:

```bash
docker compose build
docker compose run --rm --no-deps app composer install
docker compose up -d
docker compose exec app php database/seed.php
```

Сайт доступен по адресу http://localhost:8000.

Сидер создаёт таблицы и добавляет 4 категории, 18 статей и 19 связей.
Одна категория остаётся пустой, одна статья относится к двум категориям.

Если категории или статьи уже существуют, заполнение пропускается.
Сидер предназначен для первоначального заполнения пустой базы.

Остановка:

```bash
docker compose down
```

Данные MySQL сохраняются в Docker volume.

## Стили

Готовый CSS включён в репозиторий.
Для обычного запуска сайта сборка стилей не требуется.

Исходник: `assets/scss/style.scss`.
Результат сборки: `public/css/style.css`.

Установка зависимостей и сборка:

```bash
docker compose run --rm assets npm ci
docker compose run --rm assets npm run build
```

Автоматическая пересборка при изменениях:

```bash
docker compose run --rm assets npm run watch
```

## Структура

- `public/` — страницы сайта и публичные файлы.
- `src/` — настройка приложения, подключение к базе и функции работы с данными.
- `templates/` — шаблоны Smarty.
- `database/` — SQL-схема и скрипт сидинга.
- `assets/scss/` — исходные стили.

## Принятые решения

Статьи и категории связаны через таблицу `post_category`.
Это позволяет одной статье относиться к нескольким категориям.
Составной первичный ключ исключает повторные связи.

Для работы с MySQL используется PDO.
Значения передаются через подготовленные запросы.
Сортировка выбирается из разрешённых SQL-фрагментов.

Просмотр учитывается при каждом открытии страницы статьи.
Счётчик увеличивается непосредственно в MySQL.

Похожие статьи выбираются по наличию общей категории.
Текущая статья исключается, результат сортируется по дате публикации.

Для стабильного порядка при одинаковых датах или просмотрах
используется дополнительная сортировка по ID.

Вывод текста экранируется средствами Smarty.
Изображения тестовых статей используют локальную SVG-заглушку.

Docker-окружение предназначено для локального запуска.
В нём используются встроенный сервер PHP и тестовые пароли.

## Использование ИИ

ИИ помог:
- подготовить конфигурацию Docker;
- подготовить код SQL-схемы, сидинга и шаблонов;
- подготовить первоначальные варианты PHP-функций и обработчиков страниц;
- подготовить SCSS и команды сборки;
- сформулировать документацию.

Разработка фиксировалась отдельными коммитами по этапам.
